# 게임 참고 지식

확인일: 2026-09-14. 현재 문서 작성의 배경지식이며 완전한 게임 사양서가 아니다. 내부 문서의 설계안, 뷰어에 표시된 데이터, 영상에서 관찰한 UI를 구분한다. 밸런스 수치와 라이브 적용 여부는 작업 시 최신 자료를 확인한다.

## 게임과 콘텐츠

- 공식 스토어 소개상 미소녀 수집형 RPG이며 캐릭터 상성·시너지와 팀 구성을 강조한다. 공식 App Store 소개는 실시간 전투를 명시한다.
- 내부 전투 컨텐츠 목차에 지역 제패, 특별 조달, 플러리 구역, 네메시스, 아레나, 아카이브 어센트, 이벤트 보스전이 있다.
- 공통 문서로 인게임 UI, 전투 결과 UI, 데미지 그래프, 타임 라인, 버스트 자동 사용·배속·소탕 잠금 처리, 웨이브 커스텀 이벤트가 연결되어 있다. 링크 제목 확인과 하위 문서의 상세 분석은 구별한다.
- 뷰어의 모드 이름은 작전 진행, 특별 조달, 플러리 구역, 이벤트, 어센트, 네메시스, 레이드다. 내부 명칭과 유사해도 정확한 일대일 대응은 별도 확인한다.
- 내부 신규 기획인 택배 털이는 성력 주입 재화 획득용 특별 조달 존이다. 뷰어에서 확인한 특별 조달 목록은 데이터 탈취·금품 갈취·세탁소 습격이다. 택배 털이가 보이지 않는다는 사실만으로 개발 상태를 단정하지 않는다.

## 캐릭터와 스킬

### 전투 조작과 파티 구성

- 파티는 최대 5인으로 편성한다. 1인 편성도 가능하다.
- 전투 제한 시간은 콘텐츠마다 다르므로 공통값으로 고정하지 않는다.
- PC와 NPC는 각자의 패턴에 따라 자동으로 전투한다.
- 유저가 전투 중 수동으로 조작할 수 있는 범위는 PC의 버스트 스킬 사용에 한정된다.
- 버스트 스킬은 캐릭터별로 개별 재사용 대기시간이 있으며, 유저가 원하는 타이밍에 사용할 수 있다.
- 버스트 사용 가능 상태에서 캐릭터 슬롯을 터치하면 AUTO 설정과 무관하게 현재 동작을 취소하고 즉시 버스트 스킬을 사용한다.
- 버스트 자동 사용은 AUTO와 SET 상태로 구분한다.
  - SET 상태에서는 버스트가 사용 가능 상태로 전환되는 즉시 현재 동작을 취소하고 사용한다. 재사용 대기시간, 글로벌 재사용 대기시간, 군중 제어 상태 등이 해제되는 경우를 포함한다.
  - SET 상태가 아니면서 AUTO 상태인 경우, 스킬을 선정하는 시점에 버스트가 사용 가능하면 버스트 스킬을 사용한다.
  - 버스트는 캐릭터의 기존 전투 패턴에 포함되지 않으며, AUTO 사용으로 기존 패턴이 변하지 않아야 한다.
- 동시에 여러 캐릭터가 버스트를 자동 사용 가능한 경우 SET 상태 캐릭터, AUTO 상태 캐릭터 순으로 우선한다.
  - SET 상태 캐릭터가 여러 명이면 SET 상태에 진입한 순서대로 사용한다.
  - AUTO 상태 캐릭터가 여러 명이면 최우측 슬롯부터 사용한다. 최우측 슬롯은 사거리가 짧은 캐릭터 순서에 해당한다.
- NPC는 버스트 스킬을 사용하지 않는다.
- 웨이브가 전환되어도 PC의 현재 HP와 버스트 스킬 재사용 대기시간은 초기화되지 않고 다음 웨이브로 이어진다.
- 웨이브 전환 시 PC에게 적용 중인 버프와 디버프도 해제되지 않고 유지된다.
- 현재 웨이브의 전투가 종료되면 별도의 전환 연출 없이 PC가 다음 웨이브 위치까지 달려간다. 해당 위치에 도달하면 곧바로 다음 전투를 시작한다.
- 다음 웨이브 위치로 이동하는 동안에는 버스트 스킬 재사용 대기시간과 버프·디버프의 남은 시간이 감소하지 않는다.
- 다음 웨이브 위치로 이동하는 동안에는 콘텐츠의 전투 제한 시간도 감소하지 않는다.
- 웨이브 전환 전에 전투 불능이 된 PC는 다음 웨이브에서도 전투 불능 상태를 유지한다.
- 현재 사양에서는 전투 불능 PC가 해당 스테이지 안에서 다시 전투에 참여할 수 없다.
- 모든 PC가 전투 불능이 되면 콘텐츠의 남은 전투 시간과 관계없이 즉시 패배 처리된다.
- 전투 제한 시간이 0이 되면 생존한 PC가 있더라도 즉시 패배 처리된다.
- 최종 웨이브의 모든 NPC를 처치하면 콘텐츠의 남은 전투 시간과 관계없이 즉시 승리 처리된다.
- 승리 조건과 패배 조건을 동시에 판정하지 않는다. 최종 NPC 전투 불능과 마지막 생존 PC 전투 불능이 근접한 시점에 발생하면 먼저 발생한 조건에 따라 결과를 결정한다.
- 최종 웨이브가 아닌 웨이브에서 모든 NPC가 전투 불능이 되면 즉시 다음 웨이브 위치로 이동을 시작한다.
- 현재 사양에서는 웨이브 종료 시 PC가 진행 중인 공격이나 스킬 동작을 끝낸 뒤 웨이브 전환을 진행한다. 향후 진행 중인 동작을 즉시 중단하는 방식으로 변경될 수 있다.
- 웨이브의 마지막 NPC가 전투 불능이 되는 순간 전투 제한시간이 멈춘다. PC가 진행 중인 동작을 마치는 동안과 다음 웨이브 위치로 이동하는 동안 모두 감소하지 않는다.
- 웨이브의 마지막 NPC가 전투 불능이 되는 순간 버스트 스킬 재사용 대기시간과 버프·디버프의 남은 시간도 멈춘다. PC가 진행 중인 동작을 마치는 동안과 다음 웨이브 위치로 이동하는 동안 모두 감소하지 않는다.
- 다음 웨이브 위치에 도착해 전투가 시작되면 정지했던 전투 제한시간, 버스트 스킬 재사용 대기시간, 버프·디버프 남은 시간이 다시 감소하기 시작한다.

| 구분 | 표시 명칭 |
|---|---|
| 속성 | 열정, 욕망, 의지, 이성 |
| 역할 | 탱커, 딜러, 서포터, 힐러 |
| 포지션 | 전열, 중열, 후열 |
| 진영 | 후마니타스, 베르몬트, 사군자, 무소속 |
| 별도 정보 | 등급, 소속, 캐릭터 코드, 프로필, 스킬, 스탯, SD, 스킨 |

- 속성 우위는 `열정 → 의지 → 욕망 → 이성 → 열정` 순으로 순환한다.
- 속성은 캐릭터에 바인딩된다.
- 현재 확인된 사양에는 전투 중 캐릭터의 바인딩 속성을 변경하는 기능이나 상황이 없다. 향후에도 변경할 수 없다는 영구 규칙으로 확정한 것은 아니다.
- 우위 속성으로 공격하면 최종 데미지에 30%를 추가 가중한다. `Attribute_Superiority_Data.final_damage_per` 값은 모든 우위 관계에서 `0.3`이다.
- 우위 속성의 최종 데미지 30% 추가 가중은 공격 주체와 관계없이 적용된다. PC가 NPC를 공격할 때와 NPC가 PC를 공격할 때 모두 동일하다. 사용자 문답으로 2026-09-16 확정했다.
- 우위 속성의 최종 데미지 30% 추가 가중은 지속 피해에도 적용된다. 사용자 문답으로 2026-09-16 확정했다.
- 속성에 따른 피해 보정은 우위 관계의 30% 증가에만 적용된다. 열위 관계를 포함하여 우위가 아닌 모든 속성 조합은 속성 보정 없이 기본 피해를 적용한다. 사용자 문답으로 2026-09-15~16 확정했다.

|---|---|---|
| 열정 | `MERCY` | 의지 |
| 욕망 | `UNITY` | 이성 |
| 의지 | `OBEY` | 욕망 |

- 캐릭터는 `CH...`, 스테이지 적은 `NP...` 코드로 연결되는 사례를 확인했다.
- 루시아(CH0001) 상세에서 일반 공격·스킬·버스트와 시작/반복 스킬 순환을 확인했다. 패시브는 효과 뷰어에서 별도 분류된다.
- 캐릭터 목록의 `NPC 포함` 필터에서 NPC의 속성·역할·포지션을 함께 확인할 수 있다. 뷰어에는 탱커·딜러·서포터·힐러 역할이 표시되지만, 이는 데이터 확인용 뷰어 표시이며 게임 화면 노출을 뜻하지 않는다.
- NP0101은 기본 공격 1개와 `전방의 가장 가까운 적` 타깃 규칙을 가진 사례다. NP0106은 기본 공격과 방어력 증가 스킬 1개를 가진 서포터형 사례로, 앞서 사용자 문답으로 확정한 일반·서포터형 몬스터 규칙과 일치한다.
- 확인한 NPC 상세 화면에는 PC 상세의 시작/반복 스킬 순환과 같은 행동 순서가 표시되지 않았다. 스킬 목록의 나열 순서만으로 NPC의 실제 사용 순서를 단정하지 않는다.
- 스킬 설명에는 대상 선택, 범위, 타격 횟수, 기준 능력치, 조건부 효과가 포함된다. 타깃 선정과 효과 적용 범위를 동일시하지 않는다.
- 예: 가까운 적, 가장 먼 적, 체력이 가장 낮은 아군, 공격력이 높은 아군 등 대상 조건이 구분된다. 회복은 치유력 기반인 사례가 있다.
- 효과 뷰어 분류: 즉시, 지속, 버프, 디버프, 군중 제어, 해제, 면역, 패시브 능력치.
- 확인한 효과 예: 피해, 회복, 보호막, 지속 피해/회복, 기절, 넉백, 매혹, 침묵, 공포, 속박, 정화, 면역, 버스트 재사용 대기 감소.
- 내부 타임 라인 문서의 `skill_categorize_type`: 1=일반 공격, 2=스킬, 3=버스트 스킬. 아이콘 참조는 `[Skill_Base_Data] - icon`. 문서에 기록된 정의이며 실제 테이블 파일을 검증한 것은 아니다.

## 스테이지 구성

뷰어 탐색 구조: 모드 → 그룹/존 → 스테이지 → 웨이브 → 등장 NPC/스킬.

- 콘텐츠 규칙은 스테이지 수, 웨이브 수, 전투 제한시간, 입장 비용, 승리 조건, 보상 방식을 결정한다.
- 각 웨이브에 배치하는 몬스터 조합은 스테이지별로 개별 설계한다.
- 몬스터 배치는 배열 형태로 선언한다. 각 몬스터의 전열·중열·후열 정보에 따라 사전에 구성한 ScriptableObject가 실제 위치를 자동으로 설정한다.
- PC 시작 위치와 다음 웨이브의 전투 위치는 테이블로 제어한다. 해당 위치값은 콘텐츠 기획자가 직접 신경 쓰거나 스테이지마다 수동 배치할 대상이 아니다.
- 전·중·후열은 고정된 전투 위치가 아니라 초기 배치 기준이다. PC와 NPC는 공격과 스킬의 사거리에 맞춰 이동한다.

- 몬스터는 설계상 일반, 정예, 보스로 크게 구분한다.
  - 일반 몬스터는 기본 공격만 사용한다. 딜러와 구분되는 서포터형 일반 몬스터는 예외적으로 버프 또는 회복 1종을 사용할 수 있다.
  - 정예 몬스터는 일반 몬스터보다 강한 형태이며 스킬 1~2종을 보유한다.
  - 보스 몬스터는 군중 제어 저항을 가진다. 보스가 등장하는 웨이브에 돌입하면 화면 상단에 보스 전용 HP바를 표시한다.
- 몬스터 역할은 내부 데이터에서 탱커, 딜러, 서포터, 힐러로 구분하지만 게임 화면에는 노출하지 않는다.
- PC 역할은 탱커, 딜러, 서포터로 구분한다. 힐러 역할은 작업 과정에서 서포터에 통합되었다.
- 몬스터의 공격 대상은 모든 몬스터에 공통된 단일 우선순위가 아니라 스킬마다 설정된 별도 타깃 규칙에 따라 선택한다.

공장 데이터 1 (`3040101`) 예시에서 확인한 필드:

- 권장 레벨, 약점 속성, 스태미나, 적 레벨.
- 임무 조건: 스테이지 클리어, 파트너 전원 생존, 전투 시간 조건.
- 반복 보상, 필드 리소스, BGM, 웨이브 배치.
- NPC별 코드·수량·레벨·속성·보스 표시·스킬 열람.
- 이 예시는 NP8101·NP8102·NP8199를 사용한다. 구체적 수량과 수치를 다른 스테이지의 기본값으로 전용하지 않는다.

## 지정 기획서에서 확인한 연결 관계

- 특별 조달 확장: `GAME_TYPE / DAILY_DUNGEON_ITEM_MODE`, `DAILY_ZONE_TYPE / DAILY_ZONE_INJECTION_MATERIAL_MODE`. 신규 존은 기존 해금·소탕 체계를 사용하도록 작성되어 있다.
- 시즌 운영: 네메시스·아레나 시작/종료 시간 변경에 `Schedule_Data.open_date / end_date` 활용을 제안한다.
- 이벤트 보스전: 피해량 최고 기록 경쟁, 무제한 도전·입장 재화 없음, 무한 체력 보스가 설계되어 있다. 보상·랭킹 표시량 등은 미결정 요소가 포함되어 있다.
- 해당 문서의 데이터 연결: `Event_Raid_Stage_Data` → `wave_group_id / wave_data`, `stage_name_id / lang_data`; `Wave_Boss_Info_Data.hpbar_split_type` 추가; `HPBAR_SPLIT_TYPE` 구분.
- 데미지 그래프는 가한 피해량·받은 피해량·회복량으로 기여도를 요약하고, 타임 라인은 스킬 시점·패턴·웨이브 흐름을 분석하는 별도 UI로 설계되어 있다.

## 화면 관찰

공개 플레이 영상의 튜토리얼 및 후속 전투 구간에서 확인:

- 측면 시점에서 PC는 화면 왼쪽, NPC는 오른쪽에 자리하고 서로 마주 보며 전투한다.
- 전투 중 캐릭터는 상대 진영 방향으로 전진해 사거리를 확보한다. 화면 상하의 위치 차이는 전·중·후열 대형을 보여주는 깊이 표현으로 관찰된다.
- 웨이브 사이에는 PC 파티가 화면 오른쪽의 다음 전투 지점으로 함께 달려간다.
- 화면 상단에 웨이브 정보·보스 이름/체력바·전투 시간·일시정지가 표시된다.
- 하단에 파티 캐릭터 초상과 상태 게이지가 배치된다.
- 피해·회복 숫자가 전장에 표시된다.
- 영상은 과거 촬영된 예시다. 등장 인원, UI 위치, 타이머 값과 영상만으로 판별할 수 없는 세부 이동 로직은 모든 콘텐츠의 고정 규칙으로 일반화하지 않는다.

## 미확인 범위

전체 캐릭터/몬스터 개별 설계, 모든 스테이지 수치, 속성 우위 외의 피해 공식, 콘텐츠별 전투 제한 시간, 최신 라이브 반영 상태는 아직 검증하지 않았다. 후속 기획에 필요한 항목을 지정 자료에서 추가 확인한다.
