# 메이크 드라마 레퍼런스

## 프로젝트 맥락

- 대상 게임: 메이크 드라마 (MAke Drama : MAD).
- 사용자 역할: 인게임 전투 콘텐츠 전담 기획자.
- 담당 범위: 전투 콘텐츠, 콘텐츠 관련 시스템, 몬스터 디자인, 레벨 디자인.
- 이 정보는 메이크 드라마 작업에만 적용한다.

## 자료 안내

| 파일 | 사용할 때 |
|---|---|
| [게임 참고 지식](game-context.md) | 게임 용어, 캐릭터/스킬/스테이지 구조를 확인할 때 |
| [지정 문서 분석](document-analysis.md) | 메이크 드라마의 실제 기획서 사례와 문서 유형별 구성을 참고할 때 |
| [출처와 확인 상태](sources.md) | 노션·뷰어·공식 소개·영상의 경로와 열람 범위를 확인할 때 |

공통 작성 원칙은 [디폴트 영역](../../default/writing-rules.md)에 있다. 이 영역의 개별 데이터 키·콘텐츠 규칙·예시는 다른 프로젝트의 기본값이 아니다.

## 사용 범위

개발 노션에는 여러 작업자의 문서가 혼재한다. 사용자 지정 문서 5개는 작성 사례이며, 전투 콘텐츠 목차와 뷰어·영상은 게임 구조 참고 자료다. 새 문서가 추가되면 사용 목적과 출처를 함께 기록한다.
