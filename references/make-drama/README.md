# 메이크 드라마 레퍼런스

## 프로젝트 맥락

- 대상 게임: 메이크 드라마 (MAke Drama : MAD).
- 사용자 역할: 인게임 전투 콘텐츠 전담 기획자.
- 담당 범위: 전투 콘텐츠, 콘텐츠 관련 시스템, 몬스터 디자인, 레벨 디자인.
- 이 정보는 메이크 드라마 작업에만 적용한다.

## 자료 안내

| 파일 | 사용할 때 |
|---|---|
| [게임 참고 지식](game-context.md) | 게임 용어, 캐릭터/스킬/스테이지 구조를 확인할 때 |
| [지정 문서 분석](document-analysis.md) | 메이크 드라마의 실제 기획서 사례와 문서 유형별 구성을 참고할 때 |
| [출처와 확인 상태](sources.md) | 노션·뷰어·공식 소개·영상의 경로와 열람 범위를 확인할 때 |
| [기획 작업 영역](designs/README.md) | 대화에서 발전시키는 아이디어·검토 중 기획·픽스된 기획을 실제 게임 정보와 분리할 때 |

공통 작성 원칙은 [디폴트 영역](../../default/writing-rules.md)에 있다. 이 영역의 개별 데이터 키·콘텐츠 규칙·예시는 다른 프로젝트의 기본값이 아니다.

## 사용 범위

개발 노션에는 여러 작업자의 문서가 혼재한다. 사용자 지정 문서 5개는 작성 사례이며, 전투 콘텐츠 목차와 뷰어·영상은 게임 구조 참고 자료다. 새 문서가 추가되면 사용 목적과 출처를 함께 기록한다.

실제 개발 노션: https://app.notion.com/p/26d08a0561328044898ed45e4b70f93b

저장된 요약은 2026-09-14 확인 기준이다. 비공개 노션 원문 열람에는 별도의 계정 접근 권한이 필요하다.

## 정보와 기획의 구분

- 질문과 답변, 테이블, 기존 문서에서 확인한 현재 게임 정보는 `game-context.md`에 저장한다.
- 이 작업에서 새로 제시하거나 발전시킨 아이디어와 기획안은 `designs/` 아래 주제별 문서에 저장한다.
- 사용자가 명시적으로 픽스하기 전까지 기획안의 상태는 `아이디어` 또는 `검토 중`으로 유지한다.
- 사용자가 픽스한 기획은 `픽스`로 표시한다. 실제 빌드 적용 또는 현재 게임 사양으로 확인되기 전에는 `game-context.md`에 합치지 않는다.
