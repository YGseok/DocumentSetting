# 메이크 드라마 기획 작업 영역

대화에서 새로 만드는 아이디어와 기획안을 현재 게임 정보와 분리해 저장한다. 주제별 기획을 별도 Markdown 문서로 만들고 아래 상태를 문서 상단에 기록한다.

| 상태 | 의미 |
|---|---|
| 아이디어 | 방향을 탐색하는 초기 제안. 요구사항이나 구현 사양으로 간주하지 않는다. |
| 검토 중 | 규칙과 예외를 구체화하고 있으나 사용자가 픽스하지 않은 기획. |
| 픽스 | 사용자가 명시적으로 확정한 기획. 현재 빌드 적용 여부와는 별개다. |

## 저장 원칙

- 사용자의 답변이 현재 게임의 실제 동작을 설명하면 `../game-context.md`에 저장한다.
- 사용자의 답변이 신규 기획의 선택이나 방향을 결정하면 이 영역의 해당 기획 문서에 저장한다.
- 문서 완성도, 구현 가능성, 테이블 초안 존재만으로 상태를 `픽스`로 바꾸지 않는다.
- 사용자가 “픽스”, “확정”, “이 안으로 진행”처럼 명시적으로 결정했을 때만 `픽스`로 변경한다.
- 픽스된 기획도 실제 빌드 적용 또는 현재 게임 사양이라고 확인되기 전에는 `game-context.md`로 옮기지 않는다.
- 기획 문서에는 확인된 기존 사양, 신규 제안, 미결정 항목을 구분해 작성한다.

기획 문서의 기본 머리말:

```text
# 기획명

- 상태: 아이디어 | 검토 중 | 픽스
- 최종 갱신일: YYYY-MM-DD
- 관련 실제 사양: ../game-context.md의 해당 항목 또는 출처
```
